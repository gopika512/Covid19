# 🌍 COVID-19 Impact Tracker

A simple and interactive web application that displays real-time global COVID-19 statistics using the **disease.sh API**. The dashboard provides live updates on confirmed cases, recoveries, and deaths, along with a visual trend chart for better understanding of the pandemic.

---

## 📌 Features

- 📊 Live global COVID-19 statistics
- ✅ Total confirmed cases
- ❤️ Total recovered cases
- 💀 Total deaths
- 📈 Interactive chart using Chart.js
- 🌐 Real-time data fetched from the disease.sh API
- 📱 Responsive and clean user interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js

This project uses the free public API provided by **disease.sh**.

API Endpoint:

```
https://disease.sh/v3/covid-19/all
```
